# EE-design-project - Ergonomic-Mouse

## Project Overview

This project explores the custom angle-adjustable ergonimic mouse, aimed for carpal tunnel preventation and angle customization for user-comfortability.
This project will mainly emphasize functionality and electrical engineering design, including signal processing, noise handling and the development of embedded firmware.  

Currently, the project is still in progress.

## Motivation
Most commonly used flat mouse forces its user to pronate wrist and heavily contribute to conditions such as carpal tunnel syndrome. While vertical mouse exist in a market, they lack user-adaptive customization for comfortable positions.

This project aims to build a prototype of an angle-adjustable mouse which will support:

- Various angle customization to user's liking, with its angle ranging from a flat mouse to a vertical mouse

- Function to fix the angle at the desired place
